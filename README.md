# LE Studio (iOS)

Нативное iOS-приложение для **LitEnergy Automation Studio** — панели мультиаккаунтной публикации (TikTok · Telegram · ВКонтакте · Instagram · YouTube), AI-генерации видео и кросспостинга.

* Вход по паролю панели (токен хранится в Keychain).
* «Главная» — нативная сводка: аккаунты, активные задания, авто-выкладка (вкл/выкл, запуск), AI-видео (создать, квота, кастинг), последние ролики с сохранением в Фото, журнал.
* «Кросспост», «AI-видео», «Аккаунты» (TikTok / Telegram / VK), «Медиатека», «Логи» — полная веб-панель без потери функций, в стиле приложения.
* iOS 15+, SwiftUI, сборка в GitHub Actions (неподписанный IPA в Releases).

Сборка: `brew install xcodegen && xcodegen generate`, затем открыть `LEStudio.xcodeproj`.
